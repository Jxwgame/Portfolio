## 6. เตรียมตัวสัมภาษณ์

**สิ่งที่ JD เน้นแต่เรายังไม่มี — ควรอ่านไว้ล่วงหน้า**
- **SLO / SLI / error budget** — ศัพท์ SRE ที่ JD พูดถึงชัดเจน ควรอธิบายได้ว่าต่างกันยังไง
- **Toil** — นิยามคือ งานมือที่ทำซ้ำๆ ไม่สร้างคุณค่าถาวร (งาน automate monitoring ที่เราทำคือการลด toil พอดี)
- **Blameless post-mortem** — วิเคราะห์เหตุขัดข้องโดยไม่โทษคน
- **Terraform** — เป็น nice-to-have ถ้ามีเวลาลองเล่นสัก 1-2 วันจะได้พูดถึงได้
- **Kubernetes** — nice-to-have เช่นกัน เรามี Docker แล้วต่อยอดไม่ยาก

**คำถามที่ควรถาม**
- ทีม DevOps ตอนนี้กี่คน ตำแหน่งนี้เป็นคนแรกหรือมีคนทำอยู่แล้ว
- ทำงานกับทีมญี่ปุ่นและอินเดียบ่อยแค่ไหน ใช้ภาษาอะไร timezone จัดการยังไง
- on-call มีเวรยังไง หมุนเวียนกี่คน
- Hybrid เข้าออฟฟิศกี่วันต่อสัปดาห์
